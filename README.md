# Marcel Rochera

Computer Engineering student at UPC. My projects usually start from curiosity: so far that has meant working on a molecular dynamics analysis pipeline, a social network built with Ruby on Rails, a model that predicts a Pokémon's type from its Pokédex entry and an ASCII Earth lit in real time.

I mostly write Python and Ruby on Rails, and I'm learning React.

## Things I've made

**🧬 [MYC–MAX pocket analysis](https://github.com/MarcelRochera00/myc-max-pocket-analysis)**
The code behind a paper in preparation on the identification of candidate pockets at the MYC–MAX protein interface.

**⚡ [ActivityFeed](https://github.com/MarcelRochera00/activityfeed)**
A social network to post hikes, books, concerts and more. Hikes are drawn on a map from GPX files, and books and setlists are looked up through external APIs.

**📜 [Pokémon type from text](https://github.com/MarcelRochera00/pokemon-type-from-text)**
I got curious whether a Pokédex entry gives away a Pokémon's type. Partly: about 50% right, against 16% for always guessing Water, the most common type. Dragon entries are the hardest to spot.

**🌍 [ASCII Earth](https://github.com/MarcelRochera00/ascii-earth)**
A spinning Earth made of ASCII characters, lit by where the sun actually is right now.
